先记住这 3 条铁律

  • 顺序先国家医保，后商业险。娃一出生先把「落地险/居民医保」办了，再谈商业险。
  • 主次先保大人，再保小孩。经济支柱（父母）才是娃最大的「保险」。
  • 取舍不急着买寿险/返还型。保障型（消费型）优先，钱少也能把保额做高。

医保不是万能的：一张图看懂「医保内外」和费用缺口

粉丝问得最多的「医保内/医保外能不能报」，核心在这张图里。国家医保只报「目录内」且按比例/封顶线；目录外、免赔额、既往症等缺口，才是商业险该补的地方。

读图说明：矩形=费用去向；线宽=金额占比（示意模型）。医保报销后，剩余部分可能由「百万医疗」「小额医疗」「意外险」「重疾险」按各自规则覆盖，但都有免赔额、免责、等待期等限制，不是全能。

配置优先级：从「必做」到「最后考虑」

漏斗越靠上越该先办、越刚需。国家医保是地基，商业险按「大额医疗→收入中断→意外」依次补，教育金/寿险放最后。

优先级为作者科普模型。国家医保与百万医疗解决「治不起」；重疾险解决「大人请假/收入断档」；意外险补磕碰烫伤；教育金/寿险非保障刚需，预算紧可暂缓。

钱怎么分：家庭保障预算的「大人优先」原则

家庭年保费建议 ≈ 年收入 5%–10%（通用参考，非硬指标）。孩子部分建议不超过家庭保障预算的 1/3，钱优先留给经济支柱。

示意拆分：经济支柱（父母）约 70%，孩子约 30%。逻辑——大人出事对家庭现金流冲击远大于孩子，先堵最大的窟窿。

📌 新生儿投保特殊实务（新手爸妈最容易忽略）

这是新手爸妈咨询最高频、也最容易踩坑的环节。商业健康险对新生儿有硬门槛和核保流程，跟大人投保不一样。

① 投保年龄门槛：新生儿「落地险」（居民医保）出生即可办；但绝大多数重疾险、百万医疗险要求宝宝出生满 28 天且健康出院才能投保，0–27 天基本买不了商业健康险。少数少儿意外险最低支持出生满 7 天投保。早产儿/低体重儿通常还要达到矫正胎龄或体重标准、出院后观察一段时间。
② 常见体况要如实告知：早产、低出生体重、黄疸住院、卵圆孔未闭、动脉导管未闭、新生儿肺炎、ABO 溶血、新生儿窒息等，都是投保高频告知项，通常需要提供出院小结 / 儿保记录。核保结果一般分四类：标体承保（正常买） / 除外责任（某器官或某病不赔） / 延期承保（观察一段时间再看） / 拒保。结果以保险公司核保为准，不要隐瞒。
③ 实操建议：先试产品「智能核保」（线上勾选，不留下拒保记录）；过不了再走人工核保并提供完整病历；拿不准就多家同时核保、选结论最好的。有体况的宝宝不要为了顺利承保而跳过病史告知——隐瞒是导致未来拒赔的头号原因。
④ 百万医疗免赔的「现实」：百万医疗通常一般医疗年度免赔 1 万（很多产品重疾医疗 0 免赔）。不少新生儿普通住院总花费不到 1 万，百万医疗用不上——预算允许可搭配小额医疗险覆盖小额住院/门诊。

🗺 新手决策时间线：一眼看清先后节点

把「铁律 + 新生儿实务」串成一条时间线。照着走，基本不会漏关键步骤、也不会买错顺序。需要完整板块请配合上方「目录」跳转。

① 出生当天：办「落地险」（居民医保）

出生后尽快办，窗口期各地 28天/90天/6个月内不等（以当地医保局为准），按时办可追溯报销出生起住院费。

② 满 28 天 + 健康出院

这是绝大多数重疾/百万医疗的投保硬门槛；0–27 天基本买不了商业健康险，少数意外险满 7 天可投。

③ 体况先核保（不隐瞒）

早产/黄疸/卵圆孔/肺炎等：先试智能核保（线上勾选、不留拒保记录）；过不了走人工核保并交出院小结。结论可能是标体/除外/延期/拒保。

④ 投保「基础四件套」

顺序：国家医保 → 百万医疗 → 少儿重疾 → 意外险；大人保障优先于娃。预算够重疾优先保终身或「定期+终身」组合。

⑤ 过等待期 + 每年年检

早买早过疾病等待期；每年家庭情况变化后复核保额/保障是否还够，别买完就忘。

商业险三层：解决什么问题 + 条款重点看什么

三者互补不冲突。下面按「它是干嘛的」和「买时条款盯哪些」两层讲，并把常见误区一并标出。

① 少儿重疾险

作用：确诊约定重疾一次性给付一笔钱，补家长误工/康复营养费（不是「报销医药费」）。注意：并非所有重疾都「确诊即赔」——部分需实施特定手术或达到条款约定状态（如严重脑中风后遗症需存活 180 天、双目失明需永久不可逆等）。
保额：建议 ≥30万，预算够冲50万
保障期限：定期（保20-30年）保费低、易做高保额，但属阶段性过渡：到期风险
疾病覆盖：监管统一28种重疾必保；高发轻/中症看是否覆盖
赔付次数：单次 vs 多次；多次看分组/不分组、三同条款
少儿特疾：白血病、神经母细胞瘤、重症手足口病、严重脑炎/脑膜炎、严重川崎病等是否额外赔
豁免：投保人豁免：家长（投保人）若确诊重疾/身故，宝宝这份保单后续保费免交、保障继续有效（附加时父母也需健康告知，豁免本身有等待期）。
⚠ 误区：把重疾当「报销险」、保额买太低；盲目买捆绑寿险/两全的重疾，保费高保障低。
✓ 优先：高保额 + 少儿特疾额外赔 + 不分组/无三同更优；慎买捆绑寿险。

② 医疗险

作用：报销住院医疗费，补医保报不了的部分（「报销型」，花多少报多少，不治病赔钱）。
免赔额：百万医疗一般医疗年度1万（很多产品重疾医疗0免赔）；小额医疗0免赔或几百
报销范围：是否含社保外用药、自费药、进口药、院外特药/CAR-T
医院范围：通常二级及以上公立医院普通部；特需/国际部需中高端医疗
报销比例：经社保结算后住院责任多100%；但部分产品院外特药单独限比例，CAR-T仅赔清单内药品，不等于所有CAR-T疗法都赔
保证续保：保证续保≠保证承保（20年/6年/1年）
增值服务：住院垫付、就医绿通、质子重离子
⚠ 小额医疗险多为一年期、不保证续保，产品停售即无法续，仅作补充不能替代百万医疗；特药/CAR-T报销限制要看清。
✓ 优先：保证续保久 + 含外购药/特药 + 含社保外 + 重疾0免赔。

③ 意外险

作用：意外身故/伤残给付 + 意外医疗报销（磕碰烫伤、摔倒、异物）。
意外医疗：免赔额、报销比例、是否含社保外用药
身故保额：监管限额：10岁前≤20万，10-18岁≤50万，不必追高
住院津贴：每天补多少、免赔天数几天
特定意外：骨折/烧烫伤/误食异物、疫苗意外等待期是否额外保
免责：高风险运动、牙科美容通常不赔
✓ 优先：意外医疗0免赔/不限社保/100%报销。

看条款先盯这 8 个关键词

粉丝提到的「免赔额、用药限制、医保内外、保障次数」都在这。投保前把对应条款找出来对一遍，能避开大部分纠纷。鼠标悬停蓝字看术语解释。

1. 免赔额

百万医疗通常1万/年（重疾常0免赔）；小额/意外医疗多为0或几百。越低越容易用到。

2. 报销比例

经社保结算后通常100%，未经社保可能只报60%。投保选「有社保」身份，看病一定要先用医保。

3. 社保内外

国家医保只报目录内。能扩展社保外用药/自费药/进口药，才真正解决「医保外」费用。

4. 特药/外购药

靶向药、CAR-T 多需院外购买。看条款特药清单、是否含外购药；CAR-T只赔清单内药。

5. 等待期

疾病通常30-180天，意外一般无等待期（疫苗意外可能单独设）。等待期内出险不赔。

6. 既往症

投保前已患疾病/症状，通常除外或拒赔。健康告知务必如实，否则可能被解除合同。

7. 免责条款

先天性疾病（投保前未知的先天相关达重疾定义仍可能赔，非一刀切）、牙科、视力矫正、美容、高风险运动、精神疾病常在内。买前翻一遍。

8. 续保条件

是否保证续保、保几年、到期是否重核保。短期医疗险停售可能无法续，保证续保≠保证终身承保。

商业保险常见拒赔原因（也是粉丝最怕的）

不是保险公司「故意不赔」，大多是条款前置条件没满足。提前知道就能避开。

  • 未如实告知：投保时隐瞒早产、黄疸、住院史等，理赔时被发现，可能拒赔并解除合同。
  • 等待期内出险：疾病等待期内确诊或住院，医疗险/重疾险通常不赔。
  • 属于免责条款：美容整形、牙科、视力矫正、高风险运动、自杀/自伤等。
  • 既往症：投保前已有的疾病及其并发症，常被除外或拒赔。
  • 未经社保结算：以「有社保」身份投保，但看病没用医保，报销比例可能大幅下降。
  • 医院/药品不在范围内：去非约定医院，或用院外药但产品不含特药责任。
  • 未达理赔条件：重疾险需确诊约定疾病/状态或实施约定手术；医疗险需超免赔且为必要合理费用。
  • 保障次数/保额用完：多次赔付重疾次数用尽，或医疗险年度保额已用完。

买了之后怎么赔：理赔实操

家长不只关心「买什么」，也关心「出事了怎么拿钱」。通用流程如下，具体以条款与保险公司指引为准。

报案：知道保险事故后尽快报案，多数产品要求知道事故后 10 日内（具体看条款），可 App/客服电话/代理人报。
材料清单（通用）：保单号、被保人身份证/出生证、银行卡；住院：出院小结、发票原件、费用清单、诊断证明、检查报告；意外：事故说明/证明。社保已报销的，商保报「社保结算后的剩余」，记得留好社保结算单。
两个易错点：① 百万医疗务必先走社保结算，否则报销比例可能从 100% 掉到 60%；② 重疾险「确诊即赔」是多数，但部分重疾需实施约定手术或达到约定状态（如脑中风后遗症需存活 180 天），别误以为确诊当天就必赔。材料原件至少保留到理赔结案。

不只是看产品：如何看保险公司

选保险是「产品 + 公司」双维度。以下为公开可查的参考维度，不唯价格、也不唯名气。

看什么怎么看
偿付能力核心/综合偿付能力充足率，监管有红线（综合≥100%、核心≥50% 为达标底线，越高越稳）
风险综合评级监管分类评级（如 A/B/C/D），A 类更优
服务与理赔年报披露的理赔获赔率、理赔时效、投诉率；App 报案体验
稳定性股东背景、经营年限、产品停售频率
提示：在我国，人寿/健康险公司的保单受《保险法》及保险保障基金机制保护，即便公司风险处置，合法保单权益也受制度安排保障；但不同公司服务体验、续保稳定性确有差异，预算紧可优先保额与条款，服务体验作为加分项。

买前必问 11 问（拿着去问销售或自己翻条款）

粉丝搞不懂的地方，浓缩成这 11 个问题。能答清楚，基本不会买错。

  1. 医疗险免赔额多少？社保内外都能报吗？特药/CAR-T 含哪些、报销比例？
  2. 重疾险保多少病种？高发的 28 种重疾是否都覆盖？少儿特疾额外赔哪些？
  3. 重疾险单次还是多次？分组还是不分组？有没有「三同条款」？
  4. 意外险意外医疗免赔额多少？报销比例？是否含社保外用药？疫苗意外有没有单独等待期？
  5. 是否包含院外药/外购药/特药清单？CAR-T 赔清单内还是全部疗法？
  6. 疾病等待期多久？意外险有没有等待期？
  7. 既往症怎么定义？我家娃的情况（如早产、黄疸、卵圆孔）算不算？
  8. 医院范围是二级及以上公立医院普通部吗？特需/国际部报不报？
  9. 续保条件？保证续保多少年？保证续保≠保证终身承保，到期/停售怎么办？
  10. 免责条款有哪些我容易忽略的？先天相关疾病的理赔边界？
  11. 如果宝宝有早产、黄疸住院、卵圆孔未闭等新生儿异常，核保可能给什么结论？会不会做责任除外？

对号入座：按你最担心的风险选险种

粉丝群反馈的核心问题，直接对应到险种和条款要点。没有「最完美方案」，只有「最对路配置」。

你最担心优先配置条款重点盯常见误区
大病住院花不起国家医保 + 百万医疗保证续保年限、是否含社保外、特药清单、重疾0免赔以为医保全包；忽略1万免赔
小病门诊/住院也想报+ 小额医疗险免赔额、门诊/住院都报吗、报销比例小额医疗多不保证续保，不能替代百万医疗
医保外用药/进口药挑含外购药/特药的百万医疗特药清单、是否含CAR-T、外购药定义普通百万医疗可能只报社保内
白血病/少儿重疾+ 少儿重疾险保额、少儿特疾额外赔、多次/分组/三同把重疾当「报销险」；保额太低；忽略到期风险

常见问题 FAQ

Q：28 天内能买商业健康险吗？
A：基本不能。绝大多数重疾/百万医疗要求出生满 28 天且健康出院；少数意外险满 7 天可投。先办落地险。

Q：早产儿能买吗？
A：多数需满 28 天且健康出院，早产/低体重常触发核保，可能延期或需人工核保，结论以保险公司为准。

Q：有黄疸能买吗？
A：生理性黄疸消退后通常可标体；病理性黄疸需提供病历资料走核保，勿隐瞒。

Q：卵圆孔未闭能买吗？
A：多数 ≤3mm 且有自愈趋势可标体或除外，需核保；具体看缺损大小与复查结果。

Q：医保和商保怎么衔接报销？
A：先社保结算，拿结算单给商保报「剩余部分」；百万医疗未经社保结算报销比例会降。

Q：定期重疾到期买不到怎么办？
A：预算够优先终身，或「定期+终身」组合锁部分终身保障；别等到期前才补。

⚠ 国家医保（落地险）：这条最容易踩地方政策

新生儿「落地险」关键点：出生后按规定时限内参保，通常可追溯报销出生起的医疗费。但参保窗口期各地差异大——常见为出生后 28天 / 90天 / 6个月内不等（以当地为准，务必以当地医保局公布为准）。
办理：在户籍地或居住证所在地办居民医保，出生后尽快办、别拖过窗口。
查询方式：拨打 12333（人社服务热线）/ 12393（医疗保障服务热线），或微信搜「XX省/市医保局」公众号，关键词「新生儿参保」「城乡居民医保」。具体天数、材料、渠道以当地医保局/税务窗口最新发布为准，本页不给死数。
